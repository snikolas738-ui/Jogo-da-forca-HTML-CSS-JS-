# Jogo da Forca

Aplicação web do clássico Jogo da Forca, desenvolvida em HTML, CSS e JavaScript puro, sem uso de frameworks ou bibliotecas externas.

## Funcionalidades

- Sorteio aleatório de palavras com categoria exibida
- Teclado virtual clicável (também funciona digitando no teclado físico)
- Desenho do boneco da forca em SVG, que é revelado peça por peça a cada erro
- Contador de erros e tentativas
- Mensagem de vitória ou derrota ao final
- Botão para reiniciar e jogar novamente

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (manipulação de DOM, eventos de teclado)
- SVG para o desenho da forca

## Como usar

1. Baixe o arquivo `index.html`
2. Abra no navegador
3. Clique nas letras do teclado virtual (ou digite no teclado do computador) para tentar adivinhar a palavra
4. Tente acertar antes de errar 6 vezes
